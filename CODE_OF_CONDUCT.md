# Code of conduct

Argue about the engine, the numbers and the code as hard as you like, and leave people out of it. No harassment,
slurs, personal attacks, threats, or other people's private information, in issues, pull requests or anywhere the project
is discussed in its name.

Maintainers can edit, hide or delete comments, lock or close threads, and block users who break these rules.

To report a problem privately, use [GitHub's private reporting form](https://github.com/mottopanikeiku/doomformer/security/advisories/new)
and say it is a conduct report. To report a public comment, use "Report content" on it.
