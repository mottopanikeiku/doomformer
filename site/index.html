Conveyor belts carry voodoo dolls across weighted lines that change light levels or floor heights. Staircases turn those values into activations by controlling how many dolls pass. Python reads the results from the running game and fails on any difference from the integer reference.

DOOM reads handwritten MNIST digits with 97% accuracy: all 10,000 test digits ran through four tile maps with Python passing values between them, and every value read from the game matched NumPy exactly, while DrawPad, below, runs the same network in one map.

Walk a digit, DOOM reads it

# arrows walk, hold Ctrl to draw, Space: READ
doomformer draw
# headless: the marine walks a 7
doomformer draw --digit 7
# the same map as a WAD that GZDoom plays without Python
doomformer draw --build drawpad

How it works

  1. your networkPyTorch / NumPy
  2. integersquantised
  3. a DOOM maplanes, gates, lava lines, doors
  4. ViZDoom runs itvoodoo dolls walk
  5. read backlight levels and plane heights
  6. EXACTevery readback equals the NumPy integer reference

DOOM turns every extra player start into a voodoo doll, a copy of the player that rides conveyors and triggers every line it crosses, so an activation of 5 is five dolls. A staircase lets a doll past each step only if the value clears it, which gives ReLU, rounding and clamping in one shape.

A second floor move in the same sector and tic is lost, a teleport cancels lines crossed earlier that tic, and objects far from a BSP node land in the wrong room, so these constraints shape the compiler (engine details).

counter.wad (2006) counts with voodoo dolls, conway.wad runs Game of Life, and Danny Spencer's calculator adds numbers. Doomformer compiles neural networks into these mechanics and checks their outputs against NumPy.

Build your own

Compile a network into a map and let its outputs open doors, flash lights or shove the marine.

import numpy as np
import doomformer as df

# 2 inputs -> [a AND b, a OR b] -> 2 outputs, all integers
net = df.MLP(
    weights=[np.array([[1, 1], [1, 1]]), np.array([[1, 0], [0, 1]])],
    biases=[np.array([-1, 0]), np.array([0, 0])],
    thresholds=[np.array([1]), np.array([1])],
    signed_input=False,
)
with df.compile(net) as brain:
    for x in ([0, 0], [1, 0], [1, 1]):
        # computed by voodoo dolls; raises df.MismatchError on any difference from net.reference
        print(x, "->", brain(np.array(x)).tolist())
    brain.record([np.array([0, 1]), np.array([1, 1])], "dolls.gif")   # film the dolls doing it
