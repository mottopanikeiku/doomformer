Integer neural networks compiled into ZDoom maps. Voodoo dolls do the arithmetic, and every value is checked against NumPy with tolerance 0.

  • tolerance 0
  • MIT
GitHub repository Install Films How it works Docs

A number is a crowd of voodoo dolls on a conveyor belt. An activation is a staircase they climb. A weight is a line they cross, and each crossing changes a light level or a floor height. When the dolls stop, Python reads the values back and compares each one with a NumPy integer reference. One value off by one and the run fails.

Walk a digit, DOOM reads it

# arrows walk, hold Ctrl to draw, Space: READ
doomformer draw
# headless: the marine walks a 7
doomformer draw --digit 7

How it works

  1. your networkPyTorch / NumPy
  2. integersquantised
  3. a DOOM maplanes, gates, lava lines, doors
  4. ViZDoom runs itvoodoo dolls walk
  5. read backlight levels and plane heights
  6. EXACTevery value equals the NumPy integer reference

DOOM turns every extra player start into a voodoo doll: a copy of the player that rides conveyors and triggers every line it crosses. An activation of 5 is five dolls. A staircase lets a doll past each step only if the value clears it, which gives ReLU, rounding and clamping in one shape.

The engine has sharp edges. A second floor move on one sector in the same tic is lost. A teleport cancels lines crossed earlier in the same tic. Things far from a BSP node land in the wrong room. The full list is in HOW_IT_WORKS.md.

Computers in DOOM maps exist already. counter.wad (2006) counts with voodoo dolls, conway.wad runs Game of Life, and Danny Spencer's calculator adds numbers. Doomformer adds a compiler for neural networks, a list of engine behaviours that break exactness, and the tolerance-0 check.

Bigger experiments

Each run is exact against its reference. Scope and picked seeds are in DEMOS.md.

Build your own

Compile a network into a map and let its outputs open doors, flash lights or shove the marine.

import numpy as np
import doomformer as df

# 2 inputs -> [a AND b, a OR b] -> 2 outputs, all integers
net = df.MLP(
    weights=[np.array([[1, 1], [1, 1]]), np.array([[1, 0], [0, 1]])],
    biases=[np.array([-1, 0]), np.array([0, 0])],
    thresholds=[np.array([1]), np.array([1])],
    signed_input=False,
)
with df.compile(net) as brain:
    for x in ([0, 0], [1, 0], [1, 1]):
        # computed by voodoo dolls; raises df.MismatchError on any difference from net.reference
        print(x, "->", brain(np.array(x)).tolist())
    brain.record([np.array([0, 1]), np.array([1, 1])], "dolls.gif")   # film the dolls doing it

The guide is BUILD_YOUR_OWN.md, and there are twelve small runnable examples.

Limits

  • DOOM is slow. A small MLP runs about 23,000 times slower than NumPy (Speed).
  • Only the runs are checked. EXACT means DOOM equals the integer network. It does not say the answer is right.
  • Attention is integer attention. No model has LayerNorm.
  • The marine's policies imitate a scripted aimbot. There is no reinforcement learning.
  • Showcased seeds, lesions and names are picked (list).
