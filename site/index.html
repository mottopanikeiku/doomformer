A number is a crowd of voodoo dolls on a conveyor belt. An activation function is a staircase they have to climb. A matrix multiply is dolls running across lava lines, each line raising a room's light level. Attention is dolls squeezing under ceilings that another number has lowered. When the dolls stop, the light levels are read back out of the running game and compared bit for bit with an independent integer reference. One value off by one and the run fails.

Walk a digit, DOOM reads it

doomformer draw               # opens a window: arrow keys to walk, hold Ctrl to draw, Space on the READ switch
doomformer draw --digit 7     # headless: the marine walks a 7

How it works

  1. your networkPyTorch / NumPy
  2. integersquantised
  3. a DOOM maplanes, gates, lava lines, doors
  4. ViZDoom runs itvoodoo dolls walk
  5. read backsector light levels
  6. EXACTevery value equals the NumPy integer reference

DOOM turns every extra player-1 start into a voodoo doll: a copy of the player that rides conveyors and triggers every line it crosses. An activation of 5 is five dolls. A staircase lets a doll past each step only if the value clears that step's height, which gives ReLU, rounding and clamping in one shape. Sums accumulate in sector light levels, which turn out to be saturating int16 values.

Getting exact results meant measuring the engine. Two floor moves on one sector in the same tic: one is silently lost. A teleport line cancels lines crossed earlier in the same tic. Maps wider than about 34,000 units put things in the wrong room. One value off by one raises MismatchError. The full list is in HOW_IT_WORKS.md and engine_limits.md.

Build your own

Compile your own network into a DOOM map and let its outputs open doors, flash lights or shove the marine.

import doomformer as df

net = df.MLP.from_torch(my_torch_mlp, calib_x, levels=8)
print(net.quantization_report(test_x))    # how close the integer model is to your float model
with df.compile(net, actions={"y0": [df.act.door_open(tag=7)]}, world=my_room) as brain:
    y = brain(net.encode(x))              # computed by voodoo dolls, verified exactly
    brain.record([net.encode(x)], "dolls.gif")

The guide is BUILD_YOUR_OWN.md, and there are twelve small runnable examples.
