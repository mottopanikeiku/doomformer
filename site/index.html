Integer neural networks compiled into ZDoom maps. Voodoo dolls do the arithmetic, and every value is checked against NumPy with tolerance 0.

  • tolerance 0
  • MIT
GitHub repository Install Films How it works Docs

A number is a crowd of voodoo dolls on a conveyor belt. An activation is a staircase they have to climb. A weight is a line they cross, and each crossing adds to a sector's light level or to a plane height. Attention is dolls squeezing under ceilings that another number has lowered. When the dolls stop, Python reads the values back out of the running game and compares each with an independent NumPy integer reference. One value off by one and the run fails.

Walk a digit, DOOM reads it

# arrows walk, hold Ctrl to draw, Space: READ
doomformer draw
# headless: the marine walks a 7
doomformer draw --digit 7

His brain is the level

Times are from an idle 16-core arm64 Linux machine running up to 8 games at once; hello and draw use one game. With 2 games, demo took about 1 minute and demo --softmax about 3.5 minutes on a busy machine, and ask took 20 minutes on 3 games.

hello runs a 4-6-5-3 integer MLP. mnist --image my7.png reads your own digit. demo is a 1-layer transformer trained on 136 official level names, cut into 38 tile maps; --nightmare is the 2-layer model (56,390 dolls); ask is a 2-layer transformer trained on 189 DOOM facts.

  • "Not in its training names" is a low bar: 29 of 30 unselected samples of the 2-layer model at temperature 200 are new, and the default demo writes one of its 136 training names for 6 of 10 seeds (the output says which). The default seed (20) is picked.
  • DEMON CANYON, the name --nightmare wrote, is a hand-picked sample (seed 2, temperature 150; the number of seeds tried before it is not recorded). The 2-layer model was trained on 11,341 of 12,934 cleaned level names.
  • ask gets 94.7 % of its training paraphrases right and 35.4 % of new wordings of the same facts. "what does iddqd do" is a training question and answers GOD MODE. A question outside the 189 facts gets an answer that is exact and meaningless.

How it works

  1. your networkPyTorch / NumPy
  2. integersquantised
  3. a DOOM maplanes, gates, lava lines, doors
  4. ViZDoom runs itvoodoo dolls walk
  5. read backlight levels and plane heights
  6. EXACTevery value equals the NumPy integer reference

DOOM turns every extra player-1 start into a voodoo doll: a copy of the player that rides conveyors and triggers every line it crosses. An activation of 5 is five dolls. A staircase lets a doll past each step only if the value clears that step's height, which gives ReLU, rounding and clamping in one shape. Sums accumulate in sector light levels (saturating int16 values) in tile maps; in one-map designs a weight line moves a later gate's floor or ceiling, so the sum is a plane height.

Two floor moves on one sector in the same tic: one is silently lost. A teleport line cancels lines crossed earlier in the same tic. Maps wider than about 34,000 units put things in the wrong room. One value off by one raises MismatchError. The full list is in HOW_IT_WORKS.md and engine_limits.md.

Computers inside DOOM maps exist already. counter.wad (2006) is a 4-bit counter built from voodoo dolls and conveyor belts, conway.wad runs Game of Life in a Boom map, and Danny Spencer's DOOM calculator is an adding machine. Doomformer adds a compiler from integer networks to ZDoom maps, a measured list of engine behaviours that break exactness, and a tolerance-0 check against a NumPy reference.

Bigger experiments

Each is exact against its reference; scope and picked seeds are in DEMOS.md and FLY.md.

Run it yourself

From a clone (pip install -e .). demos/README.md lists each command, its time and what it prints.

  • python -m demos.brainlevel: 5 decisions in about 4 min; --decisions 50 --seed 4 is the 50 of 50 run, about 31 min.
  • python -m demos.aimlearn: 2 lives in about 3 min; --lives 5 --seed 4 takes about 11 min.
  • python -m demos.flyloop: 40 steps in about 3 min; --steps 900 runs to the end at step 169, about 13 min.
  • python -m demos.lobotomy: the lesion scan and 3 decisions in DOOM, about 1.5 min.

Build your own

Compile your own network into a DOOM map and let its outputs open doors, flash lights or shove the marine.

import numpy as np
import doomformer as df

# 2 inputs -> [a AND b, a OR b] -> 2 outputs, all integers
net = df.MLP(
    weights=[np.array([[1, 1], [1, 1]]), np.array([[1, 0], [0, 1]])],
    biases=[np.array([-1, 0]), np.array([0, 0])],
    thresholds=[np.array([1]), np.array([1])],
    signed_input=False,
)
with df.compile(net) as brain:
    for x in ([0, 0], [1, 0], [1, 1]):
        # computed by voodoo dolls; raises df.MismatchError on any difference from net.reference
        print(x, "->", brain(np.array(x)).tolist())
    brain.record([np.array([0, 1]), np.array([1, 1])], "dolls.gif")   # film the dolls doing it

The guide is BUILD_YOUR_OWN.md, and there are twelve small runnable examples.

Limits

  • DOOM is slow. One pass of a 12→16→6 MLP takes 726 ms in DOOM and 11.1 µs in NumPy, about 65,000 times slower (30 timed runs, Speed); a fly-circuit step is about 73,000 times slower. A handwritten digit is 163 seconds of real-time DOOM at the default schedule and 8 seconds at --opt 3.
  • The check is integer equality over the runs that were made, and says nothing about inputs that were not run. EXACT means DOOM equals the integer network; it says nothing about whether the answer is right.
  • Attention is integer attention: ReLU-style in most models, softmax computed by the dolls in three. No model has LayerNorm (doomnames_modern has an integer RMSNorm), and none is a drop-in float transformer.
  • The marine's policies imitate a scripted aimbot that sees exact positions. Python bins them into 86 possible observations and supplies the labels. There is no reward-driven RL and no learning from pixels.
  • Showcased seeds, lesions and names are picked. Seeds and selection lists each pick.
